# HTTP Methods

## About the Project

This project is created using Python and FastAPI to learn and practice HTTP methods.

## HTTP Methods

* **GET:** Retrieve data.
* **POST:** Create new data.
* **PUT:** Update existing data.
* **PATCH:** Partially update data.
* **DELETE:** Delete data.

## Technologies Used

* Python
* FastAPI
* JSON

## Project Files

* `main.py` – Contains the application code.
* `student.json` – Stores student information.
* `README.md` – Contains project documentation.

## How to Run

1. Install FastAPI:

   ```bash
   pip install fastapi uvicorn
   ```
2. Run the application:

   ```bash
   uvicorn main:app --reload
   ```
3. Open the API documentation in your browser:
   `http://127.0.0.1:8000/docs`

## Purpose

The purpose of this project is to understand how HTTP methods work in a Python API.
